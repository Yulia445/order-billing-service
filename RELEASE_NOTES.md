# Release Notes — v1.1.0

## Added
- Додано спеціальний базовий тариф доставки 80.0 для міста "Kyiv".
- Додано явний параметр ставки податку taxRate (зі значенням за замовчуванням 0.20) у функцію розрахунку стандартного інвойсу.

## Changed
- Збільшено коефіцієнт розрахунку вартості доставки за вагу з 12.0 до 15.0 за кілограм.
- Виконано повний архітектурний рефакторинг модуля billing.js із переходом до еталонного рівня зв'язності Data Coupling.

## Breaking Changes
- Змінено сигнатури функцій розрахунку (calculateDeliveryCost тепер приймає примітивні параметри city та weightKg замість об'єкта customerProfile).
- Видалено глобальну змінну стану GLOBAL_TAX_RATE.
- Видалено керуючий прапорець modeFlag та єдину функцію processInvoice — логіку розділено на окремі функції processStandardInvoice та processTaxExemptInvoice.
